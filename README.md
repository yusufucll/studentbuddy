# StudentBuddy

StudentBuddy is an interactive, lightweight web application developed as part of the **UCLL Teamvaardigheden (Soft Skills & Scrum)** simulation project (2026). It provides higher education students with evidence-based study tips, structured planning strategies, and restorative break exercises—completely accessible without any login barrier.

## Technology Stack
- **HTML5**: Semantic and accessible markup
- **CSS3**: Custom properties, responsive Flexbox and CSS Grid
- **JavaScript (ES6+)**: Modular, zero-dependency client-side interactivity
- **Hosting**: GitHub Pages (Static site deployment)

## Running Locally
No installation or build steps required. Simply open `index.html` in any modern web browser:
```bash
# Clone the repository
git clone https://github.com/yusufucll/studentbuddy.git

# Navigate to the folder
cd studentbuddy

# Open index.html in your browser
```
